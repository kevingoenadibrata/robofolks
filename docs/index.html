Animated pixel-robot avatars · no dependencies

Give your agents a face.

robofolks draws a pixel robot for any string — an agent's name, a username, a project path — and animates it to show what that agent is doing: working, waiting on you, or idle. The same string always builds the same robot, and the animated SVG plays with no JavaScript.

robofolks at a glance

An MIT-licensed JavaScript library for avatars that show state, built for AI agent dashboards and useful anywhere a name needs a face.

Use it

npm install robofolks — or skip installing and point an <img> at an SVG you generated.

Web component

Works in plain HTML, Vue, Svelte, anywhere.

// registers <robo-folk>
import 'robofolks/element';

<robo-folk seed="kevingo"
  state="active"></robo-folk>

React

Renders the SVG itself, so server rendering needs no hydration.

import { RoboFolk } from 'robofolks/react';

<RoboFolk seed="kevingo"
  state="active" size={48} />

A file on disk

An SVG that plays itself, a PNG, or a sprite sheet for a game engine.

npx robofolks svg kevingo \
  --state active -o kevingo.svg

npx robofolks sheet kevingo -o sheet.png

Anywhere else

Pure functions: seed in, SVG string out. Node, workers, build time.

import { folkTraits, folkAnimatedSvg }
  from 'robofolks';

folkAnimatedSvg('kevingo', 'needs');

Questions

The ones that come up most. More detail in the README.

What is robofolks?

robofolks is a free, open-source JavaScript library that draws animated pixel-robot avatars. Give it any string, such as an agent's name, a username or a project path, and it always draws the same robot for it. Each robot can show a state (working, needs you, idle) or walk in four directions.

How is it different from DiceBear or an identicon?

Identicons and static avatar sets like DiceBear answer “which account is this.” robofolks answers “what is this thing doing right now”: the robot animates to show whether an agent is working, blocked on you, or idle. It also exports PNGs and game-ready sprite sheets, and has no dependencies. If you only need a static robot, DiceBear is a good choice.

How many different robots are there?

567: 7 paints × 3 builds (walker, tank, ball) × 3 antennas × 3 ear types × 3 chest panels. It's a hand-drawn pixel set rather than a parametric face generator, so a dashboard of twenty agents won't repeat in practice, and the animated states carry most of the recognition.

Does the same string always get the same robot?

Yes, for the life of a major version. Which robot 50 seeds pick, and every combination of parts, are pinned by snapshot tests, so any change to how a robot looks ships as a breaking change.

Do the animations need JavaScript?

No. folkAnimatedSvg returns a self-contained SVG animated with CSS keyframes, so it plays in an <img> tag, a GitHub README or documentation. Each one is 1–3 kB gzipped.

Which browsers and frameworks does it work with?

Chrome, Firefox and Safari. The <robo-folk> web component works in plain HTML, Vue, Svelte and React 19; robofolks/react supports React 18 and 19 with server rendering; the core functions run in Node, Deno, Bun and workers; and there is a CLI.

Is it accessible?

Each robot is an image to assistive technology, labelled “Robot avatar, working” and so on, and you can set aria-label yourself. Robots hold still when the reader asks for reduced motion.

Can I use it commercially?

Yes. robofolks is MIT licensed, with no attribution required.
