Seeded pixel avatars · no dependencies

Every string gets a robot.

A username, an email, a project path — the same string always builds the same robot, down to its antenna. They animate themselves in an SVG, with no JavaScript needed to play it.

One seed each

Every robot below is drawn from the label under it. Pick one to load it above.

Four things a robot does

Working, needing you, dozing — and walking in any of four directions, four frames each.

Three builds, and the bits

The seed picks a build, antenna, ears and chest panel. Set any of them by hand when you'd rather choose.

Use it

npm install robofolks — or skip installing and point an <img> at an SVG you generated.

Web component

Works in plain HTML, Vue, Svelte, anywhere.

// registers <robo-folk>
import 'robofolks/element';

<robo-folk seed="kevingo"
  state="active"></robo-folk>

React

Renders the SVG itself, so server rendering needs no hydration.

import { RoboFolk } from 'robofolks/react';

<RoboFolk seed="kevingo"
  state="active" size={48} />

A file on disk

An SVG that plays itself, a PNG, or a sprite sheet for a game engine.

npx robofolks svg kevingo \
  --state active -o kevingo.svg

npx robofolks sheet kevingo -o sheet.png

Anywhere else

Pure functions: seed in, SVG string out. Node, workers, build time.

import { folkTraits, folkAnimatedSvg }
  from 'robofolks';

folkAnimatedSvg('kevingo', 'needs');
